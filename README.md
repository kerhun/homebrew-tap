# kerhun/tap

Homebrew tap for [Tentacl Crew](https://github.com/kerhun/tentacl-crew).

```
brew tap kerhun/tap
brew trust kerhun/tap
brew install --cask tentacl-crew
```

Homebrew asks you to trust every tap outside homebrew/core and homebrew/cask, hence the `brew trust` step. The recommended install is the one-line `curl` in the [Tentacl Crew README](https://github.com/kerhun/tentacl-crew#install).
